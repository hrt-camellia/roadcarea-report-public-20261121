# 固定路侧摄像头道路冰雪分割迁移评估

本仓库仅发布报告网页、60张评价照片、GT/预测/误差覆盖图、统计图与指标CSV。

## 查看网页

由本仓库main分支的`docs/`目录通过GitHub Pages托管。页面包含三联图、方案切换、机位筛选、误差图、放大与CSV导出；没有服务器推理或付费实例依赖。

## 数据与评价口径

共300张、30个已知固定摄像头；每机位按登记时间划分6张训练、2张验证、2张后期评价。网页展示60张后期评价图与5种冻结方案。道路内GT和预测均使用同一人工道路模板相交。不代表未见摄像头或独立新时段验证。

## 公开范围

不含模型权重、LabelMe JSON、原始GT/ROI二值文件、二值预测文件、私有完整ZIP、凭据或本地运行目录。可视化覆盖图本身会显示道路和冰雪区域，公开后任何人可下载；不以去掉原始掩码作为素材保密保证。
